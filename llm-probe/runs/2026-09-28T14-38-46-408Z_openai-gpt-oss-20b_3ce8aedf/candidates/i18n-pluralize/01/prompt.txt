Translate and format a string using input.locales, input.lang, input.key, and input.params.
Rules:
- input.locales[lang][key] can be a plain string with '{var}' placeholders, or a plural object: { zero?: string, one?: string, other: string }.
- If it is a plural object, choose:
  - params.count === 0 and 'zero' exists -> use zero
  - params.count === 1 and 'one' exists -> use one
  - otherwise -> use other
- Replace '{var}' with params[var]. Inside plural strings, replace '#' with params.count.
- If key is missing in input.locales[lang], fallback to input.locales['en'][key]. If still missing, return key itself.
- Return the resulting string.

Implement exactly:
export function solve(input) { /* return a JSON-compatible value */ }

Rules: use synchronous JavaScript ES2023 only; do not use imports, require, files, network, subprocesses, async, or timers; do not mutate input.

Examples:
input: {"locales":{"en":{"cart_summary":{"zero":"You have no items, {name}","one":"You have 1 item, {name}","other":"You have # items, {name}"}}},"lang":"en","key":"cart_summary","params":{"count":3,"name":"Alice"}}
output: "You have 3 items, Alice"
