**2. Handling Variables (`STORE`, `LOAD`):**

*   `LOAD <var>`: Retrieve from `memory[var]`, push to stack. Check if variable exists.

**3. Handling Comparisons (`EQ`, `GT`, `LT`):**
These follow the pattern of binary operations (pop b, pop a, calculate result, push 1/0).
*   Pop two values: $b$ then $a$.
*   Calculate boolean result ($a == b$, $a > b$, $a < b$).
*   Push integer representation (1 or 0).

**4. Handling Subroutines (`CALL`, `RET`):**

    *   Pop return address $R$.

The existing structure handles jumps (`JMP`, `JZ`, `JNZ`) by setting `program_counter` directly, and then the end of the loop increments it *unless* a jump occurred. This is correct for relative jumping within the current iteration.

For `CALL`: We set `program_counter = label_map[name]`. The subsequent increment will correctly move to the start of the subroutine.
For `RET`: We pop $R$. We must set `program_counter` such that after the loop's automatic increment, it lands exactly on $R$. So, we set `program_counter = R - 1`.
