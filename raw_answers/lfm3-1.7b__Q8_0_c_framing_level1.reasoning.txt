We need to implement a fixed-size ring buffer in C99. Requirements:
- Buffer size: 512 bytes (#define BUFFER_SIZE 512 or static array of 512 elements).
- No dynamic memory allocation (static only). Use static memory.
- Pure C99, include <stdint.h>.
- Functions:
  - void ringbuf_init(void) — initializes or resets buffer to empty initial state.
  - int ringbuf_push(uint8_t byte) — pushes one byte. Returns 0 on success, -1 if full (already contains 512 bytes).
  - int ringbuf_pop(void) — pops one byte following FIFO. Returns byte value on success, or -1 if buffer empty.
  - int ringbuf_available(void) — returns current number of bytes stored (0 to 512).
  - int ringbuf_free_space(void) — returns remaining free space in buffer (512 - available).
