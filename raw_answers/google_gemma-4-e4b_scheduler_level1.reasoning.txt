Kahn's Algorithm Steps:
1. Initialize the graph representation (adjacency list: what tasks depend on me).
2. Calculate the in-degree for every task (number of prerequisites it has).
3. Initialize a queue with all tasks having an in-degree of 0 (no dependencies).
4. While the queue is not empty:
    a. Dequeue a task `T`. Add `T` to the result list.
    b. For every neighbor `N` that depends on `T`:
        i. Decrement the in-degree of `N`.
        ii. If the in-degree of `N` becomes 0, enqueue `N`.
5. Check for cycles: If the number of tasks in the result list is less than the total number of unique tasks, a cycle exists. Return `None`. Otherwise, return the result list.
