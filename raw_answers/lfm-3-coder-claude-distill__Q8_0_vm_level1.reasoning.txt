I need to implement a simple stack-based language interpreter in a single Python file. Let me break this down carefully.

**Supported Instructions:**
- `PUSH <n>` — push number n onto the stack
- `POP` — pop value from the stack
- `ADD` — pop two values (b, then a), push their sum
- `SUB` — pop two values (b, then a), push a - b
- `MUL` — pop two values, push product
- `DIV` — pop two values (b, then a), push a // b
- `DUP` — duplicate value on top of the stack
- `SWAP` — swap top two values
- `PRINT` — print top of stack

**Comments:**
- Empty lines and lines starting with "#" are comments → skip them

**Error Handling:**
- Not enough values for an operation → raise clear error with line number
- Division by zero → raise clear error with line number

**Return Value:**
- `run(program: str) -> list[str]` returning a list of printed strings (output from PRINT)

**Output Format:** Only the code in a single ```python ... ``` block, no explanations outside.

def run(program: str) -> list[str]:
    stack = []
    outputs = []

    lines = program.splitlines()

    for line_num, raw_line in enumerate(lines, start=1):
        stripped = raw_line.strip()
        
        # Skip empty lines and comments
        if not stripped or stripped.startswith('#'):
            continue
        
        parts = stripped.split()
        if not parts:
            continue  # safety

        op = parts[0].upper()

        try:
            if op == 'PUSH':
                if len(parts) < 2:

                try:
                    value = int(parts[1])
                except ValueError:
                    raise ValueError(f"Line {line_num}: PUSH expects a number, got '{parts[1]}'")
                stack.append(value)

            elif op == 'POP':
                if len(stack) < 1:
                    raise ValueError(f"Line {line_num}: POP requires at least one value on the stack")
                stack.pop()

            elif op in ('ADD', 'SUB', 'MUL', 'DIV'):
                if len(stack) < 2:
                    raise ValueError(f"Line {line_num}: Operation '{op}' requires two values, got {len(stack)}")
                
                b = stack.pop()
                a = stack.pop()
                
                if op == 'ADD':
                    result = a + b
                elif op == 'SUB':
                    result = a - b

                    result = a * b
                elif op == 'DIV':
                    if b == 0:
                        raise ValueError(f"Line {line_num}: DIV by zero (b={b})")
                    result = a // b

                stack.append(result)

            elif op == 'DUP':
                if len(stack) < 1:
                    raise ValueError(f"Line {line_num}: DUP requires at least one value on the stack")
                stack.append(stack[-1])

                raise ValueError(f"Unknown instruction '{op}' on line {line_num}")
